# DEADWEIGHT_2 -- built and live-verified locally for weeks but never actually deployed to the

# deadweight-var -- D2 has no --match-log flag wired to a mounted path yet, real deferred
# follow-up). Runs --no-auth for this first live deployment: no IDUNA M2M agent/secret has been
# provisioned for deadweight_2 yet -- named follow-up (wire real IDUNA auth), not an oversight;
# matches the documented local-dev/CI convention (DEADWEIGHT_2/scripts/build.sh already uses
# --no-auth). Reached externally through tcp-edge (the one shared TCP LB rule on the game IP),
# not its own LoadBalancer -- see images/tcp-edge/nginx.conf. Image: DEADWEIGHT_2/scripts/build-image.sh.
